# KickON 이용약관 구현 계획

**목표:** 실제 운영 중인 KickON 앱 기능과 공개 개인정보 처리방침·계정 삭제 정책에 맞는 이용약관을 `/terms`에 제공하고 모든 법적 문서 푸터를 연결한다.

**구조:** 기존 `admin` 앱의 `(legal)` 라우트와 `LegalPage` 컴포넌트를 그대로 사용한다. 공통 컴포넌트에는 선택적인 문서 버전·최종 수정일 표시만 추가하고 기존 개인정보 처리방침과 계정 삭제 페이지의 출력은 유지한다. 랜딩 페이지는 공개 법적 문서 도메인의 `/terms/`로 연결한다.

**검증:** 먼저 정적 회귀 테스트를 추가해 약관 15개 조항, 실제 기능, 개인정보·삭제 정합성, 유료 조항 제외, 푸터 3개 링크를 고정한다. 이후 관리자 앱 테스트·타입 검사·린트·빌드와 랜딩 테스트·린트·빌드를 실행하고 `/terms`를 모바일·데스크톱에서 확인한다.

## 작업

1. 관리자 앱에 실패하는 이용약관 회귀 테스트 추가
2. `LegalPage`에 선택적 버전·최종 수정일 메타데이터 추가
3. `/terms` 페이지와 15개 조항 작성
4. 관리자 앱 및 랜딩 푸터에 이용약관 링크 추가
5. 개인정보 처리방침·계정 삭제·위치정보·UGC·유료 기능 정합성 검증
6. 정적 검사, 빌드, 브라우저 반응형·링크 검증

## 법률 검토 필요

- 운영 주체의 법적 명칭, 대표자와 주소
- 위치기반서비스사업 신고 또는 적용 예외 및 별도 위치기반서비스 이용약관 필요 여부
- 만 14세 이상 가입 정책과 고지 방식
- 사용자 콘텐츠 처리 범위와 외부 경기 데이터 계약
- 약관 변경 고지 기간 및 분쟁 관할 문구
