# 킥온 랜딩 화면

홈·주요 기능·직관 기록·이용 안내 및 세 문서는 같은 React 앱을 사용합니다. 내부 링크는 History API로 전환하며 경기장 배경·안개·헤더를 유지합니다. 주소는 홈을 제외하고 끝 슬래시 없이 통일하며, 예전 슬래시·index.html 주소는 브라우저에서 정규화합니다. 직접 URL 열기와 뒤로/앞으로 이동을 지원합니다.

주요 기능의 경기 일정 장면은 앱 형태의 2026년 10월 월간 달력과 강원–인천 경기 카드 예시를 사용합니다. 경기일 점·18일 선택 표시 뒤 경기 카드가 나타납니다. 16px 설명 글씨와 밝은 색으로 가독성을 높였습니다. 주요 기능은 날짜 선택·경기 카드 펼침, 경기 진행·알림 도착, 팬 메시지 등장을 10초 장면으로 보여 줍니다. 세 장면은 자동 전환되며 직접 선택하면 해당 장면을 유지합니다. 경기 일정과 팬 커뮤니티 모션은 반복되고 실시간 경기는 종료 상태를 유지합니다. 숨겨진 탭 정지와 동작 줄이기를 지원합니다. 하단 번호·일시정지 표시는 제거했으며 설명은 모션 캔버스 바깥에 배치합니다. 기능 선택 버튼은 호버·키보드 포커스에서 파란색으로 강조됩니다.

직관 기록은 기존 프로젝트의 경기장·응원 연출 사진 두 장을 줄과 집게로 걸어둔 형태입니다. 실제 회원 기록은 조회하지 않는 예시 이미지입니다. 사진은 자연스럽게 움직이며 별도의 재생 제어 버튼은 표시하지 않습니다. 동작 줄이기 설정은 계속 지원합니다.

`/policies`에서 이용약관(`/terms`), 개인정보 처리방침(`/privacy`), 계정 삭제 요청(`/account-deletion`)을 고릅니다. 원래 문서 본문을 보존하며 읽기 영역 안에서 목차 이동·스크롤을 지원합니다.

`navigation.js`는 로고·모바일 메뉴 동작을 공유하고, 홈의 서버 지표·한국 시간 D+ 계산은 `main.js`에 유지합니다. 화면별 이벤트·타이머는 화면이 해제될 때 정리합니다.

## 문의 모달
데스크톱·모바일 문의하기 버튼은 네이비 모달을 엽니다. 이벤트·협업·앱 문의 유형과 이름 또는 소속, 회신 이메일, 문의 내용을 입력합니다. 필수 항목·길이·이메일 형식을 검사합니다. Escape·닫기·취소를 지원하며 모바일 메뉴는 모달을 열기 전에 닫습니다.

확인 버튼은 Supabase Edge Function을 통해 Resend에 발송 요청을 보냅니다. 수신 주소는 `kickon.offical@gmail.com`으로 고정하며, 서버가 Resend 접수 ID를 확인한 경우에만 접수 완료를 표시합니다. 실패하면 입력을 유지하고 동일 문의의 재시도에는 같은 전송 번호를 사용합니다. 서버의 비밀 키는 브라우저에 포함하지 않습니다.

운영 Supabase에 전송 제한 SQL과 함수를 배포하고 발신 주소·허용 Origin을 설정했습니다. AWS Route 53 인증 레코드 3개로 Resend 발신 도메인을 Verified 인증했으며, kickon.kr 전용 Sending access 키를 서버 Secret에 저장했습니다. localhost:5174의 문의 모달에서 테스트 문의 1건을 보내 접수 완료 화면과 Resend의 Delivered 이벤트를 확인했습니다. 공개 kickon.kr은 아직 기존 정적 화면이며, 최신 화면의 S3/CloudFront 반영은 별도 단계입니다. 상세 연결 순서는 [문의 메일 활성화](contact-email.md)를 참고합니다.

실시간 경기의 시간 안내는 13px, 카드 상단 정보는 12px, 골 알림은 13–15px로 확대했습니다. 문의 모달의 소개 문구와 전송 안내 문구는 표시하지 않습니다.

팬 메시지의 작성자 이름은 11px입니다. 득점 알림은 킥온 로고와 함께 “인천유나이티드 골!” 및 “후반 23분 · 인천 1 : 0 포항”을 표시하는 모션 예시이며, 실제 경기의 득점 시각을 조회하지 않습니다.

실시간 경기 모션은 경기 카드 등장 → 킥오프 → 경기 시작 알림 → 진행 표시가 가운데에 이르면 인천 득점 알림 → 끝에 도달하면 경기 종료 알림 순서입니다. 점수는 0:0에서 1:0으로 한 번 올라가며, 마지막 점수와 종료 알림은 장면이 끝날 때까지 유지합니다. 세 알림은 같은 위치에서 순서대로 교체되며 다음 장면 직전에 초기 점수로 되감지 않습니다. 다시 실시간 경기 장면을 열면 처음부터 재생합니다. 동작 줄이기에서는 마지막 점수와 종료 알림만 표시합니다.

모바일(720px 이하)은 Mona12 원본 픽셀 글꼴을 한 번만 그려, 작은 글자 위의 반투명 도트 패턴이 획을 흐리게 하지 않도록 합니다. 홈·주요 기능·직관 기록·이용 안내·세 문서의 제목은 36px이며 법적 문서 제목의 자간은 0입니다. 문의 제목은 24px·줄높이 28px, 안내 카드 번호는 12px로 맞춥니다. 골 알림 글자에는 모션 캔버스 축소의 역배율을 적용해 안정 구간에서 원래 글자 크기를 유지합니다. 데스크톱의 원형 도트 패턴은 유지합니다. Chrome 모바일 크기 320·390·430·720px에서 전체 7개 페이지의 제목 잘림과 색·패턴을 확인했습니다.
